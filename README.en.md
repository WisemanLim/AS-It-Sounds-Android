# as-it-sounds-android

Native Android app built with Jetpack Compose — transcribes audio/video on-device and displays Korean phonetic transliteration alongside Korean translation.

> **Scaffold info**: Generated by `wise-dev-standard` plugin / profile `android-compose` / domain `edtech`.

## Tech Stack

| Layer | Tool |
|-------|------|
| Language | Kotlin |
| UI Framework | Jetpack Compose (Material 3) |
| State Management | ViewModel + StateFlow (MVVM) |
| Navigation | Navigation Compose |
| Local DB | Room (SQLite) |
| Preferences | DataStore |
| ASR | whisper.cpp Android JNI (ggerganov/whisper.cpp) |
| Audio Decode | MediaExtractor + MediaCodec → 16kHz mono |
| Media Playback | ExoPlayer (Media3) |
| Translation | ML Kit Translation (on-device) + MyMemory / LibreTranslate / DeepL |
| Background | WorkManager (CoroutineWorker) |
| DI | Hilt |
| Build System | Gradle (Kotlin DSL) + Version Catalog |
| Min SDK | API 26 (Android 8.0) |
| Deployment | Fastlane (supply) → Play Store |
| CI/CD | GitHub Actions |

## Prerequisites

- **Android Studio Meerkat or later** (includes AVD Manager + SDK) — recommended
- **JDK**: System JDK 25/26 works (verified with Gradle 9.5.1 + KSP)
  - ⚠️ If `JAVA_HOME` points to a non-existent path, the build will fail. See Troubleshooting below.
- **Android SDK**: `~/Library/Android/sdk` (auto-installed with Android Studio)
- Ruby & Bundler (`gem install bundler`) + Fastlane (`bundle install`) _(for deployment)_
- Google Play Developer account + service account JSON _(for Play Store deployment)_

## Quick Start

### Step 1 — Start an Emulator

`make dev` installs the APK on a connected device/emulator. **You must start an emulator first.**

```bash
# Option A: from terminal (background)
~/Library/Android/sdk/emulator/emulator -avd Medium_Phone &

# Option B: Android Studio
# Device Manager → AVD list → ▶ Run
```

If no AVD exists, create one in Android Studio → **Device Manager → Create Device**.

List available AVDs:
```bash
~/Library/Android/sdk/emulator/emulator -list-avds
```

### Step 2 — Build and Install

```bash
# After emulator finishes booting:
make dev     # build + install on emulator/device
```

Build APK only (no emulator needed):
```bash
./gradlew assembleDevDebug
# output: app/build/outputs/apk/dev/debug/app-dev-debug.apk
```

Open in Android Studio: `File > Open > as-it-sounds-android`

## Troubleshooting

### `JAVA_HOME is set to an invalid directory`

```
ERROR: JAVA_HOME is set to an invalid directory: /path/to/nonexistent/jdk
```

`JAVA_HOME` in `~/.zshrc` (or `~/.bashrc`) points to a path that does not exist.

```bash
# List installed JDKs
/usr/libexec/java_home -V

# Update ~/.zshrc to an existing path (example)
export JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-25.jdk/Contents/Home

# Apply
source ~/.zshrc
```

### `No connected devices!`

```
DeviceException: No connected devices!
```

Emulator is not running or still booting. Complete Step 1 first.

Check connected devices:
```bash
~/Library/Android/sdk/platform-tools/adb devices
```

### Gradle + JDK 25/26 compatibility note

This project uses **KSP** (Kotlin Symbol Processing) instead of `kapt`.  
`kapt` has a `javacOptions` parsing bug on JDK 25+; migrating to KSP resolves this.  
Gradle wrapper version: **9.5.1** (embedded Kotlin supports JDK 25 version string parsing).
